7.2.2 Logit, softmax és logsumexp

Definíció (logit). Legyen K≥2K\ge 2 az osztályok száma. Egy megfigyelés logitvektora z∈ℝKz\in\mathbb R^K, ahol zjz_j a jj-edik osztály aktiváció előtti pontszáma; a jj indexet a könyv jelölési szerződésének megfelelően 0,…,K−10,\ldots,K-1 között használjuk, mert a PyTorch célindex is 0-tól indul. A batchelt logit Z∈ℝN×KZ\in\mathbb R^{N\times K}, egy megfigyelés egy sor.

Definíció (softmax). A softmax:ℝK→(0,1)K\operatorname{softmax}:\mathbb R^K\to(0,1)^K leképezés pj=softmax(z)j=ezj∑k=0K−1ezk,j=0,…,K−1. p_j=\operatorname{softmax}(z)_j=\frac{e^{z_j}}{\sum_{k=0}^{K-1}e^{z_k}}, \qquad j=0,\ldots,K-1. A kimenetre pj>0p_j>0 és ∑jpj=1\sum_j p_j=1, tehát pp diszkrét valószínűségi vektorként értelmezhető. A softmax invariáns a konstans eltolásra: softmax(z+c𝟏)=softmax(z)\operatorname{softmax}(z+c\mathbf 1)=\operatorname{softmax}(z), mert a számláló és a nevező is ece^c-vel szorzódik. Ez az invariancia a gradiensre is öröklődik.

Definíció (logsumexp). A logsumexp függvény LSE(z)=log∑k=0K−1ezk. \operatorname{LSE}(z)=\log\sum_{k=0}^{K-1}e^{z_k}. Ez a softmax nevezőjének logaritmusa. A név gyakori angol rövidítése: logsumexp. A log természetes alapú, ahogy az egész könyvben.

Integer target és one-hot. Az osztályozási cél y∈{0,…,K−1}y\in\{0,\ldots,K-1\} egész index (PyTorchban int64). Az ey∈ℝKe_y\in\mathbb R^K one-hot vektor (ey)j=δjy={1,j=y,0,j≠y. (e_y)_j=\delta_{jy}= \begin{cases} 1,&j=y,\\ 0,&j\neq y. \end{cases} A batchelt cél y∈{0,…,K−1}Ny\in\{0,\ldots,K-1\}^N, a hozzá tartozó one-hot mátrix Yonehot∈{0,1}N×KY_{onehot}\in\{0,1\}^{N\times K}, ahol (Yonehot)nj=δj,yn(Y_{onehot})_{nj}=\delta_{j,y_n}.

Definíció (egy megfigyelés cross-entropy-ja logitsból). A p=softmax(z)p=\operatorname{softmax}(z) predikció és a yy célindex esetén L(z,y)=−logpy=−logezy∑kezk=−zy+LSE(z). L(z,y)=-\log p_y =-\log\frac{e^{z_y}}{\sum_k e^{z_k}} =-z_y+\operatorname{LSE}(z). Mivel py>0p_y>0 minden valós zz-re, a függvény mindenhol értelmes.

Stabil LSE. A log∑kezk\log\sum_k e^{z_k} közvetlen kiértékelése float32-ben már zk≈89z_k\approx 89 fölött inf-et ad, pedig a softmax és a veszteség jól definiált. Legyen c=maxkzkc=\max_k z_k. Ekkor LSE(z)=log(ec∑kezk−c)=c+log∑kezk−c. \operatorname{LSE}(z) =\log\left(e^c\sum_k e^{z_k-c}\right) =c+\log\sum_k e^{z_k-c}. Itt minden zk−c≤0z_k-c\le 0, ezért ezk−c∈(0,1]e^{z_k-c}\in(0,1], az összeg 11 és KK közé esik, tehát a számítás nem csordul túl. A stabil veszteség ezzel L(z,y)=−zy+c+log∑kezk−c. L(z,y)=-z_y+c+\log\sum_k e^{z_k-c}. Ha zy=cz_y=c, akkor a veszteség log∑kezk−c≤logK\log\sum_k e^{z_k-c}\le\log K.

7.2.3 Batch-veszteség és reduction

A batchelt logitokra Z∈ℝN×KZ\in\mathbb R^{N\times K} és a y∈{0,…,K−1}Ny\in\{0,\ldots,K-1\}^N célra a softmax soronként számolandó, azaz Pnj=softmax(Zn,:)jP_{nj}=\operatorname{softmax}(Z_{n,:})_j. Az átlagolt (mean) cross-entropy ℓ(Z,y)=1N∑n=1NL(Zn,:,yn)=1N∑n=1N(−Zn,yn+LSE(Zn,:)). \ell(Z,y)=\frac1N\sum_{n=1}^N L(Z_{n,:},y_n) =\frac1N\sum_{n=1}^N\left(-Z_{n,y_n}+\operatorname{LSE}(Z_{n,:})\right). A [D07] dokumentáció szerint a PyTorch torch.nn.CrossEntropyLoss logits bemenetet vár, egész osztályindex célját fogadja el, és a reduction paramétere 'mean' (alapértelmezés), 'sum' vagy 'none'. A 'none' mintánkénti veszteségvektort ad; a 'sum' a fenti összeg 1/N1/N nélkül.

7.2.4 Levezetés: a logitgradiens

Lemma (cross-entropy logitgradiense). Legyen z∈ℝKz\in\mathbb R^K, y∈{0,…,K−1}y\in\{0,\ldots,K-1\}, p=softmax(z)p=\operatorname{softmax}(z) és L(z,y)=−logpyL(z,y)=-\log p_y. Ekkor ∇zL(z,y)=p−ey. \nabla_z L(z,y)=p-e_y. A gradiens alakja ℝK\mathbb R^K, megegyezik zz alakjával.

Bizonyítás. Rögzítsük jj-t, és írjuk S=∑kezkS=\sum_k e^{z_k}, így pj=ezj/Sp_j=e^{z_j}/S. A softmax Jacobi-eleme a hányados- és láncszabályból: ∂pj∂zi=δijeziS−ezjeziS2=pi(δij−pj), \frac{\partial p_j}{\partial z_i} =\frac{\delta_{ij}e^{z_i}S-e^{z_j}e^{z_i}}{S^2} =p_i(\delta_{ij}-p_j), mert pi=ezi/Sp_i=e^{z_i}/S és pj=ezj/Sp_j=e^{z_j}/S. Ezután a L=−logpyL=-\log p_y összetett függvényre a láncszabály: ∂L∂zi=−1py∂py∂zi=−1pypi(δiy−py)=pi−δiy. \frac{\partial L}{\partial z_i} =-\frac{1}{p_y}\frac{\partial p_y}{\partial z_i} =-\frac{1}{p_y}p_i(\delta_{iy}-p_y) =p_i-\delta_{iy}. Az utolsó egyenlőséget esetszétválasztással ellenőrizzük: ha i=yi=y, akkor −1pypy(1−py)=py−1-\frac{1}{p_y}p_y(1-p_y)=p_y-1; ha i≠yi\neq y, akkor −1pypi(0−py)=pi-\frac{1}{p_y}p_i(0-p_y)=p_i. Mindkét eset éppen pi−δiyp_i-\delta_{iy}. A KK parciális deriváltat vektorba gyűjtve ∇zL=p−ey\nabla_z L=p-e_y. A shape-ellenőrzés: pp és eye_y is ℝK\mathbb R^K-beli, így a különbségük is. A lemma feltétele minden z∈ℝKz\in\mathbb R^K-ra teljesül, mert a softmax nevezője pozitív.

Következmény (batch-átlag gradiense). Ha P∈ℝN×KP\in\mathbb R^{N\times K} a soronkénti softmax kimenet és YonehotY_{onehot} a one-hot mátrix, akkor a mean redukciójú veszteség gradiense ∇Zℓ=1N(P−Yonehot)∈ℝN×K. \nabla_Z\ell=\frac1N(P-Y_{onehot})\in\mathbb R^{N\times K}. A 'sum' redukció esetén ugyanez 1/N1/N nélkül. A levezetés a Lemma mintánkénti alkalmazásából és a véges összeg linearitásából adódik. A gyakorlatban a keretrendszer az upstream gradienst gg szerint is skálázza: ha a veszteséghez egy további skalár szorzó kapcsolódik, a VJP g⋅1N(P−Yonehot)g\cdot\frac1N(P-Y_{onehot}).

7.2.5 Calibration előkép

A softmax kimenet formálisan diszkrét eloszlás, ezért sokan „valószínűségnek” nevezik. Ez a lépés heurisztika, nem bizonyított kalibrációs állítás. A cross-entropy minimalizálása a célosztály log-valószínűségét növeli, és ideális, végtelen mintás feltételek mellett a feltételes osztályeloszlást közelítheti; a véges mintán tanított modell azonban lehet túl magabiztos vagy alulmagabiztos. A kalibráció azt méri, hogy a 0,70{,}7-es konfidencia átlagosan 70%70\%-ban helyes-e. Ennek előképe éppen az itt definiált pp, de a tényleges kalibrációs elemzés külön metrikát (például ECE, reliability diagram) és független tesztadatot igényel; ezt a 23.2. Kalibráció és döntési küszöb alfejezetben tárgyaljuk.

7.2.7 Labor: véges differencia és nagy konstans eltolás

A következő kódot a hallgató futtatja; az itt közölt kimenet a képletekből számolt várt érték, nem mért futás. A fájl a lab/n026/check_ce_grad.py munkakönyvtárban van, CPU-n, float64-ben; véletlen seed nem szükséges.

# lab/n026/check_ce_grad.py
import numpy as np

def lse(z):
    c = np.max(z)
    return c + np.log(np.sum(np.exp(z - c)))

def softmax(z):
    s = np.exp(z - np.max(z))
    return s / np.sum(s)

def ce_loss(z, y):
    return -z[y] + lse(z)

def ce_grad(z, y):
    e_y = np.zeros_like(z)
    e_y[y] = 1.0
    return softmax(z) - e_y

z = np.array([2.0, -1.0, 0.5], dtype=np.float64)
y = 2
print("z =", z)
print("softmax =", softmax(z))
print("loss =", ce_loss(z, y))
g = ce_grad(z, y)
print("analytical grad =", g)

eps = 1e-5
num = np.zeros_like(z)
for i in range(z.shape[0]):
    e_i = np.zeros_like(z)
    e_i[i] = 1.0
    num[i] = (ce_loss(z + eps * e_i, y) - ce_loss(z - eps * e_i, y)) / (2.0 * eps)
print("numerical grad =", num)
print("max abs diff =", np.max(np.abs(num - g)))

shift = 1000.0
zs = z + shift
print("shifted loss =", ce_loss(zs, y))
print("shifted softmax =", softmax(zs))
print("shifted grad =", ce_grad(zs, y))

F3. Az elvárt függvény:

import numpy as np

def stable_ce_grad(z, y):
    z = np.asarray(z, dtype=np.float64)
    c = np.max(z)
    log_norm = c + np.log(np.sum(np.exp(z - c)))
    loss = -z[y] + log_norm
    e_y = np.zeros_like(z)
    e_y[y] = 1.0
    p = np.exp(z - c) / np.sum(np.exp(z - c))
    return loss, p - e_y
