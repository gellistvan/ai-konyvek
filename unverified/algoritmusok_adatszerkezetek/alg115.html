30.2 Evolúciós stratégiák, GP és differenciális evolúció

Az evolúciós algoritmusok családja a klasszikus genetikus algoritmusnál (GA) jóval tágabb. A GA jellemzően bit-, egész- vagy permutáció-alapú kromoszómákat használ, keresztezéssel és pontmutációval dolgozik, és a szelekciós nyomást arányos vagy versenyeztetéses mechanizmussal valósítja meg. A Genetikus algoritmusok és operátorok alfejezetben bemutatott keretrendszerre építve ez az alfejezet három, gyakorlatban is fontos irányzatot tárgyal: az evolúciós stratégiákat (ES), a genetikus programozást (GP) és a differenciális evolúciót (DE). A három módszer közös gyökere a populáció, a mutáció, a rekombináció és a szelekció, ám eltérő reprezentációval, operátorokkal és célterületekkel rendelkeznek.

A fejezet végére az olvasó képes lesz:

  • megkülönböztetni az ES, GP és DE reprezentációs és operátorszintű sajátosságait;
  • egy kis, ellenőrizhető optimalizálási vagy szimbolikus regressziós feladatra kiválasztani és paraméterezni a megfelelő módszert;
  • felismerni a tipikus csapdákat, mint a lépésméret rossz adaptációja, a GP-bloat vagy a DE korai konvergenciája.

A tárgyalás során a pszeudokód-tömbök 1-től indexeltek, a Python szemléltető kódok pedig 0-tól, amit minden blokknál jelzünk. A futásidőket generációnként vagy teljes futtatásra vetítve közöljük, mert az evolúciós módszerek költségét a fitness-kiértékelések száma és a reprezentáció mérete határozza meg.

30.2.1 1. Evolúciós stratégiák (ES)

Az evolúciós stratégiák Ingo Rechenberg és Hans-Paul Schwefel nevéhez köthetők; eredetileg folytonos paraméteroptimalizálásra fejlesztették ki őket. Míg a GA a genotípus bináris vagy diszkrét ábrázolására épít, az ES közvetlenül valós vektorokat használ, és a mutáció fő eszköze a Gauss-zaj.

30.2.2 1.1. Reprezentáció és jelölés

Egy egyed két részből áll:

  • x: a keresési tér egy pontja, például x ∈ R^D;
  • σ: a mutációs lépésméret(ek), gyakran dimenziónként egy szórás vagy egyetlen skalár.

A klasszikus jelölés (μ/ρ +, λ)-ES alakú, ahol:

  • μ a szülőpopuláció mérete,
  • λ az utódpopuláció mérete,
  • ρ a rekombinációban részt vevő szülők száma,
  • + azt jelenti, hogy a következő populációt a szülők és utódok uniójából választjuk (elitista), , pedig azt, hogy csak az utódokból.

Például az (1+1)-ES egyetlen szülőt és egyetlen utódot tart fenn; a (μ,λ)-ES μ szülőből λ utódot hoz létre, és a következő generációt csak az utódok legjobb μ egyedéből képezi.

30.2.3 1.2. Mutáció és önadaptáció

A mutáció Gauss-zajt ad a vektorhoz:

x' = x + σ * N(0, I)

ahol N(0, I) a dimenziónként független, egységnyi szórású normális eloszlás. A lépésméret adaptációja kritikus: túl nagy σ esetén a keresés véletlenszerű, túl kicsi σ esetén beragad. Az ES erős ötlete a önadaptáció, amely a σ értékét is az egyed részeként örökíti és mutálja:

σ' = σ * exp(τ * N(0, 1))
x' = x + σ' * N(0, I)

Itt τ tanulási paraméter, gyakran τ ≈ 1 / sqrt(2D) vagy τ ≈ 1 / sqrt(D). Az egyszerű (1+1)-ES-ben elterjedt az 1/5-ös siker szabály: ha az utóbbi generációkban a mutációk sikeres aránya nagyobb, mint 1/5, növeljük σ-t, ha kisebb, csökkentjük. Ez a szabály hozzávetőlegesen optimális lépésméretet tart fenn csúcsos, unimodális függvényeken.

30.2.4 1.3. Rekombináció

Az ES-ben a rekombináció nem feltétlenül keresztezés a GA értelmében; gyakran köztes vagy diszkrét újrakombináció:

  • Diszkrét rekombináció: minden dimenzióban az egyik szülő értékét választjuk véletlenül.
  • Köztes rekombináció: a szülők átlagát képezzük dimenziónként.
  • Globális rekombináció: minden dimenzióhoz a teljes szülőpopulációból választunk két szülőt, így a kombináció nem kötődik párokhoz.

A rekombináció feladata a jó tulajdonságok kombinálása, de az ES fő hajtóereje a mutáció és a lépésméret-adaptáció.

30.2.5 1.4. Szelekció

A (μ+λ) stratégia elitista: a következő populáció a szülők és utódok uniójának legjobb μ egyede. A (μ,λ) stratégia viszont csak az utódokból választ, így a szülők kihalnak. Ez utóbbi jobban fenntartja a diverzitást, és lehetővé teszi a lépésméret folyamatos újraértékelését, de nem őrzi meg automatikusan a legjobb megoldást. Gyakorlatban (μ,λ) ajánlott, ha a fitness zajos vagy a környezet dinamikus; (μ+λ) előnyös determinisztikus, sima függvényeken.

30.2.6 1.5. Pszeudokód: (μ/ρ +, λ)-ES

ES(μ, ρ, λ, f, alsó, felső, σ_kezd, g_max)
  Bemenet:  f fitnessfüggvény (minimalizálandó), μ, ρ, λ, keresési határok,
            σ_kezd kezdeti lépésméret, g_max generációlimit
  Kimenet:  a legjobb egyed (x*, σ*) és f(x*)
  Előfeltétel: μ ≥ 1, λ ≥ 1, ρ ≤ μ, g_max ≥ 1
  Utófeltétel: x* a futás során talált legjobb megoldás
  Leállás:   g_max elérve vagy σ_glob < 1e-12

  // Inicializálás
  for i = 1 to μ do
      x_i  ~ Uniform(alsó, felső)   // dimenziónként
      σ_i  = σ_kezd
  end for

  x_best, σ_best = a kezdeti populáció legjobbja

  for g = 1 to g_max do
      // Utódok létrehozása
      for j = 1 to λ do
          // ρ véletlen szülő kiválasztása
          I = véletlen indexek 1..μ közül, |I| = ρ
          x_r  = Rekombinál({x_i | i ∈ I})      // diszkrét vagy köztes
          σ_r  = Rekombinál({σ_i | i ∈ I})

          // Mutáció önadaptációval
          τ = 1 / sqrt(2 * D)
          σ_j = σ_r * exp(τ * N(0,1))
          for d = 1 to D do
              x_j[d] = x_r[d] + σ_j * N(0,1)
          end for
      end for

      // Kiértékelés
      for j = 1 to λ do
          fit_j = f(x_j)
      end for

      // Szelekció
      if "+" változat then
          P = a μ legjobb egyed a {szülők} ∪ {utódok} halmazból
      else   // "," változat
          P = a μ legjobb egyed az utódok közül
      end if

      // Legjobb nyilvántartása
      if min(fit_j) < f(x_best) then
          frissítsük x_best, σ_best
      end if
  end for

  return x_best, f(x_best)

Komplexitás: generációnként O(λ D) művelet a mutációhoz és O(λ) fitness-kiértékelés, amely a fitness függvény költségétől függ. A memóriaigény O((μ + λ) D).

30.2.7 1.6. Konvergencia és paraméterezés

Az ES konvergenciája a lépésméret-adaptáció minőségén múlik. A (1+1)-ES esetén az 1/5-ös siker szabály bizonyítottan konvergál bizonyos függvényosztályokon. A modern CMA-ES (Covariance Matrix Adaptation Evolution Strategy) a teljes kovarianciamátrixot adaptálja, és gyakran a legjobb választás fekete-dobozos folytonos optimalizálásra. Paraméterezési irányelvek:

  • μ jellemzően 5–15, λ 50–100; λ/μ arány 5–10 körül.
  • Kezdeti σ a keresési tér átmérőjének 1/3–1/10-e.
  • g_max a fitness-függvény kiértékelési költségétől függően 100–1000.

30.2.8 1.7. Tipikus hibák

  1. A σ nem alkalmazkodik – ha a lépésméretet nem örökítjük és nem adaptáljuk, a keresés vagy felrobban, vagy beragad.
  2. A (μ+λ) stratégia túlzott konzervativizmusa – zajos fitness esetén a szülők örökké megmaradnak, ami csökkenti a diverzitást.
  3. Skálázási érzékenység – a nyers vektorkoordináták eltérő nagyságrendje torzítja a Gauss-mutációt; ilyenkor normalizálni kell a bemenetet.

30.2.9 2. Genetikus programozás (GP)

A genetikus programozás John Koza nevéhez fűződik, és célja nem paramétervektorok, hanem végrehajtható programok vagy szimbolikus kifejezések evolválása. A GP egyedei változó méretű, hierarchikus struktúrák, leggyakrabban szintaxisfák.

30.2.10 2.1. Reprezentáció és zártság

Egy GP-egyed egy fa, amelynek belső csomópontjai a függvényhalmaz elemei (például +, -, *, védett /, sin, if), levelei pedig a terminálhalmaz elemei (például x, konstansok, érzékelőértékek). A függvényhalmaznak teljesítenie kell a zártság feltételét: minden függvénynek értelmezettnek kell lennie minden lehetséges argumentumra. Ezért a / helyett gyakran védett osztást használunk, amely 0-val osztás esetén 0-t vagy egy nagy konstansot ad vissza.

Például az x^2 + 3x - 2 kifejezés fája:

        -
       / \
      +   2
     / \
    *    *
   / \  / \
  x   x 3   x

A fa mérete (csomópontok száma) és mélysége a létrehozó operátoroktól és a korlátozásoktól függ.

30.2.11 2.2. Inicializálás

A kezdeti populációt véletlen fákkal töltjük fel. Két alapgenerátor:

  • Növekvő: a fa csomópontjait véletlenül választjuk a terminálok és függvények közül, amíg el nem érjük a maximális mélységet; ott csak terminált választunk.
  • Teljes: minden belső csomópontot függvényből, minden levelet terminálból építünk fel, így a fa kiegyensúlyozott.

A leggyakoribb stratégia a ramped half-and-half: a mélység 2 és max_mélység között változik, és minden szinten az egyedek felét növekvő, másik felét teljes módszerrel generáljuk. Ez biztosítja a méretbeli és szerkezetbeli diverzitást.

30.2.12 2.3. Genetikus műveletek

  • Rekombináció (részfa-csere): két szülőből kiválasztunk egy-egy véletlen csomópontot, majd az ott kezdődő részfákat kicseréljük. Ez a GA keresztezés GP-megfelelője, és megőrzi a szintaktikai érvényességet.
  • Pontmutáció: egy véletlen csomópontban a részfát egy azonos mértékű (vagy véletlen) új részfával cseréljük. A mutáció aránya általában alacsony, mert a keresztezés a fő variációs operátor.
  • Méretkorlát: a műveletek után ellenőrizzük, hogy a fa mélysége vagy csomópontszáma nem haladja-e meg a megengedett maximumot; ha igen, az utódot elvetjük vagy visszavágjuk.

A szelekció gyakran turnament-szelekció: k véletlen egyedből a legjobbat választjuk szülőnek. Az elitizmus itt is javasolt: a legjobb egyedet minden generációban változatlanul továbbvisszük.

30.2.13 2.4. Fitness és alkalmazások

A fitness leggyakrabban a tanulóadatokon számított hiba, például középérték-négyzetes hiba (MSE) szimbolikus regresszióban:

MSE = (1/n) * Σ (y_i - ŷ_i)^2

ahol y_i a célérték, ŷ_i a kifejezés által adott kimenet. Minimalizáljuk az MSE-t. A GP alkalmas még osztályozási szabályok, robotvezérlő programok, képfeldolgozó szűrők és jelsorozat-előrejelzők evolválására is.

30.2.14 2.5. Pszeudokód: generikus GP ciklus

GP(F, T, N, max_mélység, p_c, p_m, g_max, fitness)
  Bemenet:  F függvényhalmaz, T terminálhalmaz, N populációméret,
            max_mélység, p_c keresztezési valószínűség, p_m mutációs valószínűség,
            g_max generációlimit, fitness kiértékelő függvény
  Kimenet:  a legjobb programfa
  Előfeltétel: N ≥ 1, g_max ≥ 1, 0 ≤ p_c ≤ 1, 0 ≤ p_m ≤ 1
  Utófeltétel: a visszaadott egyed a futás során talált legjobb
  Leállás:   g_max elérve vagy fitness ≤ ε

  // Inicializálás ramped half-and-half
  populáció = Üres
  for mélység = 2 to max_mélység do
      populáció ∪= NövekvőFák(T, F, mélység, N/(max_mélység-1) fele)
      populáció ∪= TeljesFák(T, F, mélység, N/(max_mélység-1) fele)
  end for

  best = argmin fitness(populáció)

  for g = 1 to g_max do
      // Fitness kiszámítása
      for minden egyed in populáció do
          fit[egyed] = fitness(egyed)
      end for

      // Elit
      új_populáció = {best}

      while |új_populáció| < N do
          szülő1 = TurnamentSzelekció(populáció, fit, k=7)
          szülő2 = TurnamentSzelekció(populáció, fit, k=7)

          utód = Másol(szülő1)
          if Véletlenszám() < p_c then
              utód = RészfaCsere(szülő1, szülő2)
          end if
          if Véletlenszám() < p_m then
              utód = PontMutáció(utód, F, T)
          end if

          if Mélység(utód) ≤ max_mélység and CsomópontSzám(utód) ≤ max_csomópont then
              új_populáció ∪= {utód}
          end if
      end while

      populáció = új_populáció
      if fit[best] > min(fit[populáció]) then
          best = argmin fit[populáció]
      end if
  end for

  return best

Komplexitás: a generációnkénti műveletigényt a fitness-kiértékelések uralják, ezért O(N * átlagos_fa_méret * fitness_költség). A memóriaigény O(N * átlagos_fa_méret).

30.2.15 2.6. Konvergencia, bloat és paraméterezés

A GP konvergenciája gyakran lassabb, mint a GA vagy ES, mert a keresési tér hatalmas és redundáns. A leggyakoribb probléma a bloat: a fák mérete generációról generációra nő anélkül, hogy a fitness javulna. Ez az intronok (hatástalan részfák) felhalmozódásából ered. Kezelése:

  • Méretkorlát vagy parsimony nyomás: a fitnesshez hozzáadunk egy büntetést a fa méretével arányosan.
  • Operátor-szabályozás: a keresztezésnél előnyben részesítjük a kisebb részfákat.

Paraméterezési irányelvek:

  • Populációméret: 500–2000 a klasszikus GP-ben.
  • p_c = 0.9, p_m = 0.05–0.1.
  • Maximális mélység: 6–17.
  • A terminálok és függvények megválasztása erősen befolyásolja a kifejezőerőt; túl kevés függvény nem tud megoldást reprezentálni, túl sok növeli a keresési teret.

30.2.16 2.7. Tipikus hibák

  1. A zártság hiánya – például sqrt(-1) vagy log(0) futás közben, ami a fitness kiértékelését megbízhatóvá teszi.
  2. A bloat figyelmen kívül hagyása – a fák felrobbannak, a keresés lelassul, és a túlillesztés veszélye nő.
  3. Túl erős elitizmus – egyetlen jó egyed dominálhatja a populációt, ami korai konvergenciához vezet; az elit méretét korlátozni kell.

30.2.17 3. Differenciális evolúció (DE)

A differenciális evolúciót Rainer Storn és Kenneth Price fejlesztette ki az 1990-es években. Célja a folytonos, többdimenziós, nemlineáris optimalizálás, és egyszerűsége, valamint robusztussága miatt a mérnöki gyakorlatban is népszerű.

30.2.18 3.1. Reprezentáció és alapötlet

Mint az ES, a DE is valós vektorokat használ. Az alapötlet a differenciavektor: a populáció két egyede közötti különbség x_r2 - x_r3 adja a mutációs irányt és nagyságot. A differencia automatikusan csökken, ahogy a populáció konvergál, így a lépésméret adaptív.

30.2.19 3.2. Mutáció

A leggyakoribb változatok:

  • DE/rand/1: v = x_r1 + F * (x_r2 - x_r3)
  • DE/best/1: v = x_best + F * (x_r2 - x_r3)
  • DE/current-to-best/1: v = x_i + F * (x_best - x_i) + F * (x_r2 - x_r3)

Itt r1, r2, r3 egymástól és i-től különböző véletlen indexek, x_best a pillanatnyi legjobb egyed, F pedig a skálázási tényező, tipikusan 0.4 – 1.0. A mutáns vektor a populáció irányított perturbációja.

30.2.20 3.3. Rekombináció

A mutáns vektort keresztezzük a célvektorral, hogy létrehozzuk a próbavektort. A binomiális keresztezés minden dimenzióban függetlenül dönt:

u_j = v_j    ha rand(0,1) < Cr vagy j == j_rand
u_j = x_i_j  egyébként

ahol Cr a keresztezési valószínűség (0 és 1 között), j_rand pedig egy garantáltan mutánsból származó véletlen dimenzió, biztosítva, hogy a próbavektor ne legyen azonos a célvektorral.

30.2.21 3.4. Szelekció

A DE egy-az-egy elleni versengést alkalmaz: ha a próbavektor fitness-értéke jobb (minimalizálás esetén kisebb), mint a célvektoré, akkor a próbavektor lép a célvektor helyére. Ez a mechanizmus implicit elitista, mert soha nem rontja a populációt, de nem őriz meg további egyedeket a múltból.

30.2.22 3.5. Pszeudokód: DE/rand/1/bin

DE(N, D, g_max, F, Cr, alsó, felső, f)
  Bemenet:  N populációméret, D dimenziószám, g_max generációlimit,
            F skálázási tényező, Cr keresztezési valószínűség,
            alsó, felső keresési korlátok, f fitness (minimalizálandó)
  Kimenet:  legjobb vektor x_best
  Előfeltétel: N ≥ 4, D ≥ 1, g_max ≥ 1, 0 < F ≤ 2, 0 ≤ Cr ≤ 1
  Utófeltétel: x_best a teljes futás legjobb egyede
  Leállás:   g_max elérve vagy fitness ≤ ε

  // Inicializálás
  for i = 1 to N do
      for d = 1 to D do
          x_i[d] = Uniform(alsó[d], felső[d])
      end for
  end for

  x_best = argmin f(x_i)
  fit_best = f(x_best)

  for g = 1 to g_max do
      for i = 1 to N do
          // Mutáció: három különböző véletlen index
          r1, r2, r3 = VéletlenIndexek(1..N, különböző, != i)

          v = x_r1 + F * (x_r2 - x_r3)

          // Határkezelés: a v koordinátáit visszahúzzuk a korlátok közé
          for d = 1 to D do
              if v[d] < alsó[d] then v[d] = alsó[d]
              if v[d] > felső[d] then v[d] = felső[d]
          end for

          // Rekombináció: binomiális keresztezés
          j_rand = VéletlenEgész(1..D)
          for d = 1 to D do
              if Véletlenszám() < Cr or d == j_rand then
                  u[d] = v[d]
              else
                  u[d] = x_i[d]
              end if
          end for

          // Szelekció
          if f(u) ≤ f(x_i) then
              x_i = u
              if f(u) < fit_best then
                  x_best = u
                  fit_best = f(u)
              end if
          end if
      end for
  end for

  return x_best, fit_best

Komplexitás: generációnként O(N D) művelet a mutációhoz és keresztezéshez, valamint N fitness-kiértékelés. A memóriaigény O(N D).

30.2.23 3.6. Paraméterezés és konvergencia

A DE paraméterezése gyakran könnyebb, mint az ES-é, mert nincs lépésméret-vektor, csak két fő paraméter. Jellemző tartományok:

  • N = 10–50, de D növekedésével N ≈ 5*D ajánlott.
  • F = 0.5–1.0, gyakran 0.8.
  • Cr = 0.7–0.9.

A DE konvergenciája gyors lehet unimodális függvényeken, de multimodális függvényeken a DE/rand/1 lassabb, viszont robusztusabb a korai konvergenciával szemben, mint a DE/best/1. A populáció diverzitása a differenciavektor nagyságán keresztül természetes hűtést biztosít.

30.2.24 3.7. Tipikus hibák

  1. Túl nagy F – a mutációs ugrások túl nagyok, a keresés véletlenszerűvé válik.
  2. Túl kis N – a populáció nem fedi le a keresési teret, a differenciavektorok gyengék, a konvergencia stagnál.
  3. Nincs határkezelés – a mutáns vektor kikerülhet a korlátokon kívülre, ami értelmetlen fitness-értékeket okozhat; mindig szükséges a koordináták visszavetítése vagy büntetése.
  4. Determinisztikus seed hiánya – a kiértékelés reprodukálhatatlan; a laborban mindig rögzítsük a véletlenszám-generátor seedjét.

30.2.25 4. Összehasonlító áttekintés

Mindegyik módszer populáció-alapú, tehát párhuzamos keresést végez, és fitness-vezérelt, tehát a szelekció a fitness értékeken alapul. A mutáció adja a lokális perturbációt, a rekombináció pedig a populáción belüli információcserét. A konvergencia fogalma a populáció diverzitásának csökkenését és a fitness javulásának stagnálását jelenti; mindhárom módszernél kritikus a diverzitás fenntartása a korai konvergencia elkerülése érdekében.

A paraméterezés általános szabálya: először a populációméretet válasszuk a dimenziószám és a fitness kiértékelési költsége alapján, majd a mutációs/rekombinációs paramétereket hangoljuk. Minden eredményt több, eltérő seeddel végzett futtatás átlagával és szórásával adjunk meg, mert ezek a módszerek sztochasztikusak.

30.2.26 5. Labor: ES, GP és DE összehasonlítása

A labor célja, hogy a hallgató reprodukálható módon összehasonlítsa a három evolúciós módszert ugyanazon a benchmark feladaton, és a mért eredményeket elkülönítse a várt elméleti értékektől.

30.2.27 5.1. Követelmények

  • Használjunk rögzített, izolált környezetet (pl. Python 3.10+, NumPy).
  • Minden futtatáshoz rögzítsük a véletlenszám-generátor seedjét; 30 független futtatást végezzünk.
  • A benchmark függvények legyenek ellenőrizhetők, például:
    • Sphere: f(x) = Σ x_i^2, optimum f* = 0 az x* = 0 pontban.
    • Rastrigin: f(x) = 10D + Σ (x_i^2 - 10 cos(2πx_i)), optimum f* = 0.
    • Rosenbrock: f(x) = Σ [100(x_{i+1} - x_i^2)^2 + (1 - x_i)^2], optimum f* = 0 az x = (1, 1, ..., 1) pontban.
  • A dimenzió legyen D = 10, a keresési tartomány [-5.12, 5.12]^D (Rastrigin és Sphere), Rosenbrock esetén [-2.048, 2.048]^D vagy hasonló.
  • A GP feladat legyen szimbolikus regresszió: egy ismert függvény, például f(x) = x^3 - 2x + 1 mintavételezett pontjainak közelítése. A terminálhalmaz: {x, konstans[-1,1]}, függvényhalmaz: {+, -, *, védett /}. Fitness: MSE a tanulóhalmazon.

30.2.28 5.2. Mérési terv

Minden módszerre rögzítsük:

  • ES: (μ,λ) = (15,100), kezdeti σ = 1.0, τ = 1/sqrt(2D), generációk = 100.
  • DE: N = 50, F = 0.8, Cr = 0.9, generációk = 100.
  • GP: N = 500, max_mélység = 8, p_c = 0.9, p_m = 0.05, generációk = 30.

Futtassuk le mindhárom módszert mind a 30 seeddel, és rögzítsük a legjobb fitness-értéket minden futtatás végén. A mért eredmény:

  • átlag, szórás, 10. és 90. percentilis;
  • a fitness-kiértékelések teljes száma (ez a generációk és a populációméret szorzata, kivéve a GP elitizmust);
  • fal idő másodpercben.

A várt eredmény: a benchmark függvények analitikus optimuma f* = 0. A mért és várt értékeket külön táblázatban közöljük, és nem állítjuk, hogy a mért érték pontosan elérte a vártat, hacsak a tűréshatárt meg nem haladja.

30.2.29 5.3. Tesztesetek

A laborban az alábbi teszteket kell elvégezni:

  1. Determinizmus-teszt: ugyanaz a seed kétszeri futtatása azonos végeredményt ad (bitre pontosan).
  2. Elitizmus-teszt: kapcsoljuk ki az elitizmust, és ellenőrizzük, hogy a legjobb fitness monoton javul-e (ha igen, az elitizmus jól működik).
  3. Üres bemenet-teszt: a függvények érvénytelen dimenzióval (D=0) hibát jelezzenek.
  4. Határ-teszt: a DE mutáns vektor koordinátái mindig a keresési tartományban maradnak.

30.2.30 5.4. Szemléltető kódvázlat (Python, 0-tól indexelt tömbök)

Az alábbi vázlat csak szerkezeti, nem éles rendszerre szánt; a seed és a paraméterek helyőrzők.

# Python 3 (szemléltető, 0-tól indexelt tömbök)
import numpy as np

def sphere(x: np.ndarray) -> float:
    """Minimalizálandó benchmark függvény."""
    return float(np.sum(x ** 2))

def rastrigin(x: np.ndarray) -> float:
    A = 10.0
    return A * len(x) + float(np.sum(x ** 2 - A * np.cos(2 * np.pi * x)))

def differential_evolution(
    f, bounds: list[tuple[float, float]], N: int = 50,
    F: float = 0.8, Cr: float = 0.9, max_gen: int = 100,
    seed: int = 42
) -> tuple[np.ndarray, float]:
    rng = np.random.default_rng(seed)
    D = len(bounds)
    lower = np.array([b[0] for b in bounds])
    upper = np.array([b[1] for b in bounds])
    pop = lower + rng.random((N, D)) * (upper - lower)
    fitness = np.array([f(ind) for ind in pop])
    best_idx = np.argmin(fitness)
    x_best = pop[best_idx].copy()
    fit_best = fitness[best_idx]

    for _ in range(max_gen):
        for i in range(N):
            idxs = [j for j in range(N) if j != i]
            r1, r2, r3 = rng.choice(idxs, size=3, replace=False)
            v = pop[r1] + F * (pop[r2] - pop[r3])
            v = np.clip(v, lower, upper)  # határkezelés
            u = pop[i].copy()
            j_rand = rng.integers(0, D)
            for j in range(D):
                if rng.random() < Cr or j == j_rand:
                    u[j] = v[j]
            fu = f(u)
            if fu <= fitness[i]:
                pop[i] = u
                fitness[i] = fu
                if fu < fit_best:
                    x_best = u.copy()
                    fit_best = fu
    return x_best, fit_best

# Példa futtatás (a mérési naplóban rögzítendő)
best, val = differential_evolution(sphere, [(-5.12, 5.12)] * 10, seed=42)
# A kimenetet a hallgató naplózza; itt csak a szerkezet látható.

30.2.32 7. Összefoglalás és továbbvezetés

Ebben az alfejezetben az evolúciós algoritmusok három fontos változatát ismertük meg. Az ES valós vektorokon, Gauss-mutációval és önadaptáló lépésmérettel dolgozik; a GP programfákat evolvál szimbolikus kifejezések vagy vezérlőprogramok előállítására; a DE pedig a populáció differenciavektorait használja adaptív lépésméretként, és egy-az-egy elleni szelekcióval rendelkezik. Mindegyik módszernél kiemeltük a mutáció, rekombináció és populáció szerepét, valamint a konvergencia és paraméterezés gyakorlati szempontjait.
