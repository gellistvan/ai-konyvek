16.3 Hatványiteráció és iteratív sajátérték-keresés

16.3.1 Motiváció

A karakterisztikus egyenlet megoldásával csak kis mátrixok sajátértékeit számoljuk kényelmesen. Egy n×nn \times n-es mátrix esetén a determináns-kifejtés és a polinom gyökeinek keresése már közepes nn-nél is reménytelenül drága lehet, ráadásul a numerikus hibák is felerősödnek. A gyakorlatban sokszor nincs is szükség az összes sajátértékre: a PageRank algoritmusnak a legnagyobb abszolút értékű sajátértékhez tartozó irány kell, a spektrálnorma becsléséhez szintén a domináns sajátérték vagy szinguláris érték kell, a stabilitásvizsgálatoknál pedig gyakran csak azt kérdezzük, hogy a legnagyobb sajátérték abszolút értéke 11-nél kisebb-e. A hatványiteráció (power iteration) ezt a kérdést egyszerű, ismételt mátrix–vektor szorzással oldja meg, és nagy ritka mátrixokra is működik.

16.3.2 Szemléletes kép

Tekintsük az 𝐀=[2112] \mathbf{A} = \begin{bmatrix} 2 & 1 \\ 1 & 2 \end{bmatrix} mátrixot. A sajátértékei 33 és 11. A 33-hoz tartozó domináns sajátvektor 𝐯1=(1,1)/2\mathbf{v}_1=(1,1)/\sqrt{2}, azaz a 45∘45^\circ-os átló iránya. A másik sajátvektor 𝐯2=(1,−1)/2\mathbf{v}_2=(1,-1)/\sqrt{2}. Ha az 𝐱0=(1,0)\mathbf{x}_0=(1,0) kezdővektort felírjuk 𝐯1\mathbf{v}_1 és 𝐯2\mathbf{v}_2 lineáris kombinációjaként, akkor mindkét irányból tartalmaz valamennyit. Amikor az 𝐀\mathbf{A} mátrixszal szorzunk, a 𝐯1\mathbf{v}_1-komponens háromszorosára nyúlik, a 𝐯2\mathbf{v}_2-komponens csak egyszeresére. Minden szorzás után a domináns irány komponense arányaiban jobban megnő, így egyre inkább a (1,1)(1,1) átlóhoz fordul a vektor. Ha közben a vektor hosszát minden lépésben visszanormáljuk, a nagyság nem robban fel, de az irány fokozatosan a domináns sajátvektorhoz közelít.

16.3.3 Definíció: a hatványiteráció és a Rayleigh-hányados

Definíció. Legyen 𝐀∈ℝn×n\mathbf{A}\in\mathbb{R}^{n\times n}, és tegyük fel, hogy egyetlen domináns sajátértéke van, azaz |λ1|>|λ2|≥|λ3|≥⋯≥|λn|, |\lambda_1|>|\lambda_2|\ge|\lambda_3|\ge\cdots\ge|\lambda_n|, és λ1\lambda_1 valós. Válasszunk ∥𝐱0∥=1\|\mathbf{x}_0\|=1 kezdővektort. A hatványiteráció lépése: 𝐲k=𝐀𝐱k−1,𝐱k=𝐲k∥𝐲k∥. \mathbf{y}_k=\mathbf{A}\mathbf{x}_{k-1},\qquad \mathbf{x}_k=\frac{\mathbf{y}_k}{\|\mathbf{y}_k\|}. Ha az 𝐱0\mathbf{x}_0 sajátbázisbeli kifejtésében a domináns együttható nemnulla, azaz c1≠0c_1\ne0, akkor 𝐱k→𝐯1\mathbf{x}_k\to \mathbf{v}_1 (előjeltől eltekintve), ahol 𝐯1\mathbf{v}_1 a λ1\lambda_1-hez tartozó egységhosszú jobb sajátvektor. Negatív λ1\lambda_1 esetén 𝐱k\mathbf{x}_k előjele lépésenként váltakozik, az iránya mégis 𝐯1\mathbf{v}_1-hez tart.

Megjegyzés: mit jelent a c1≠0c_1\ne0 feltétel? A c1≠0c_1\ne0 feltétel nem azonos azzal, hogy 𝐱0\mathbf{x}_0 euklideszi értelemben merőleges 𝐯1\mathbf{v}_1-re: nem szimmetrikus 𝐀\mathbf{A} esetén a helyes feltétel 𝐰1⊤𝐱0≠0\mathbf{w}_1^\top\mathbf{x}_0\ne0, ahol 𝐰1\mathbf{w}_1 a λ1\lambda_1-hez tartozó bal sajátvektor (𝐀⊤𝐰1=λ1𝐰1\mathbf{A}^\top\mathbf{w}_1=\lambda_1\mathbf{w}_1). Szimmetrikus 𝐀\mathbf{A} esetén 𝐰1=𝐯1\mathbf{w}_1=\mathbf{v}_1, ezért ott az euklideszi merőlegesség valóban c1=0c_1=0-t jelent.

A domináns sajátérték közelítésére a Rayleigh-hányados (Rayleigh quotient) szolgál: r(𝐱)=𝐱⊤𝐀𝐱𝐱⊤𝐱. r(\mathbf{x})=\frac{\mathbf{x}^\top \mathbf{A}\mathbf{x}}{\mathbf{x}^\top \mathbf{x}}. Normált 𝐱\mathbf{x} esetén a nevező 11, így r(𝐱)=𝐱⊤𝐀𝐱r(\mathbf{x})=\mathbf{x}^\top \mathbf{A}\mathbf{x}. Ha 𝐱k≈𝐯1\mathbf{x}_k\approx \mathbf{v}_1, akkor r(𝐱k)≈λ1r(\mathbf{x}_k)\approx \lambda_1.

16.3.4 Kidolgozott példa

Használjuk az 𝐀=[2112]\mathbf{A}=\begin{bmatrix}2&1\\1&2\end{bmatrix} mátrixot és az 𝐱0=(1,0)\mathbf{x}_0=(1,0) kezdővektort. A domináns sajátértéket ismerjük: λ1=3\lambda_1=3, domináns sajátvektor 𝐯1=(0,7071;0,7071)\mathbf{v}_1=(0{,}7071;\; 0{,}7071).

Első lépés. Kiszámítjuk: 𝐲1=𝐀𝐱0=[21],∥𝐲1∥=22+12=5≈2,2361. \mathbf{y}_1=\mathbf{A}\mathbf{x}_0=\begin{bmatrix}2\\1\end{bmatrix},\quad \|\mathbf{y}_1\|=\sqrt{2^2+1^2}=\sqrt{5}\approx 2{,}2361. Így 𝐱1=15[21]=[0,89440,4472]. \mathbf{x}_1=\frac{1}{\sqrt{5}}\begin{bmatrix}2\\1\end{bmatrix} =\begin{bmatrix}0{,}8944\\0{,}4472\end{bmatrix}. A Rayleigh-hányados: r(𝐱1)=𝐱1⊤𝐀𝐱1=25⋅5+15⋅45=2+45=2,8. r(\mathbf{x}_1)=\mathbf{x}_1^\top\mathbf{A}\mathbf{x}_1= \frac{2}{\sqrt{5}}\cdot \sqrt{5}+\frac{1}{\sqrt{5}}\cdot \frac{4}{\sqrt{5}} =2+\frac{4}{5}=2{,}8.

Második lépés. 𝐲2=𝐀𝐱1=[2⋅0,8944+1⋅0,44721⋅0,8944+2⋅0,4472]=[2,23611,7889]. \mathbf{y}_2=\mathbf{A}\mathbf{x}_1= \begin{bmatrix}2\cdot 0{,}8944+1\cdot 0{,}4472\\ 1\cdot 0{,}8944+2\cdot 0{,}4472\end{bmatrix} = \begin{bmatrix}2{,}2361\\1{,}7889\end{bmatrix}. A norma 2,23612+1,78892≈2,8647\sqrt{2{,}2361^2+1{,}7889^2}\approx 2{,}8647, így 𝐱2≈[0,78090,6247]. \mathbf{x}_2\approx \begin{bmatrix}0{,}7809\\0{,}6247\end{bmatrix}. A Rayleigh-hányadoshoz előbb 𝐀𝐱2\mathbf{A}\mathbf{x}_2 kell (nem az előző lépés 𝐲2=𝐀𝐱1\mathbf{y}_2=\mathbf{A}\mathbf{x}_1 vektora!): 𝐀𝐱2≈[2⋅0,7809+0,62470,7809+2⋅0,6247]=[2,18652,0303], \mathbf{A}\mathbf{x}_2\approx \begin{bmatrix}2\cdot 0{,}7809+0{,}6247\\0{,}7809+2\cdot 0{,}6247\end{bmatrix} = \begin{bmatrix}2{,}1865\\2{,}0303\end{bmatrix}, r(𝐱2)≈0,7809⋅2,1865+0,6247⋅2,0303≈1,7074+1,2683=2,9757. r(\mathbf{x}_2)\approx 0{,}7809\cdot 2{,}1865+0{,}6247\cdot 2{,}0303 \approx 1{,}7074+1{,}2683=2{,}9757. A négy tizedesre kerekített vektorokkal kapott érték az utolsó jegyben eltérhet a pontos r(𝐱2)≈2,9756r(\mathbf{x}_2)\approx 2{,}9756 értéktől; 𝐱2\mathbf{x}_2 már közelebb van a domináns irányhoz, mint 𝐱1\mathbf{x}_1. Látszik, hogy az irány a (0,7071;0,7071)(0{,}7071;0{,}7071) felé halad, és a Rayleigh-hányados 33-hoz tart.

16.3.5 Miért éppen a domináns irányhoz konvergál?

Tegyük fel, hogy az 𝐀\mathbf{A} mátrix diagonalizálható, és a sajátvektorok 𝐯1,…,𝐯n\mathbf{v}_1,\dots,\mathbf{v}_n bázist alkotnak. A kezdővektor felírható: 𝐱0=c1𝐯1+c2𝐯2+⋯+cn𝐯n. \mathbf{x}_0=c_1\mathbf{v}_1+c_2\mathbf{v}_2+\cdots+c_n\mathbf{v}_n. Ha c1≠0c_1\ne 0, akkor a kk-adik szorzat: 𝐀k𝐱0=c1λ1k𝐯1+c2λ2k𝐯2+⋯+cnλnk𝐯n. \mathbf{A}^k\mathbf{x}_0 = c_1\lambda_1^k\mathbf{v}_1+c_2\lambda_2^k\mathbf{v}_2+\cdots+c_n\lambda_n^k\mathbf{v}_n. Emeljünk ki λ1k\lambda_1^k-t: 𝐀k𝐱0=λ1k(c1𝐯1+c2(λ2λ1)k𝐯2+⋯+cn(λnλ1)k𝐯n). \mathbf{A}^k\mathbf{x}_0 = \lambda_1^k\Big( c_1\mathbf{v}_1 + c_2\!\left(\frac{\lambda_2}{\lambda_1}\right)^k\!\mathbf{v}_2 +\cdots+ c_n\!\left(\frac{\lambda_n}{\lambda_1}\right)^k\!\mathbf{v}_n \Big). Mivel |λi/λ1|<1|\lambda_i/\lambda_1|<1, a zárójelben a 𝐯1\mathbf{v}_1-en kívüli tagok nullához tartanak. A normálás kiejti a közös λ1k\lambda_1^k skalárt, ezért az irány 𝐯1\mathbf{v}_1-hez konvergál. Ez a levezetés a hatványiteráció matematikai magja.

A konvergenciasebességet a két legnagyobb abszolút értékű sajátérték aránya, |λ2λ1|, \left|\frac{\lambda_2}{\lambda_1}\right|, határozza meg. A fenti példában ez 1/3≈0,3331/3\approx 0{,}333, ezért már néhány lépés után jól látható a konvergencia. Ha az arány 0,990{,}99, lassú a módszer; ha |λ1|=|λ2||\lambda_1|=|\lambda_2|, de λ1≠λ2\lambda_1\ne\lambda_2 (ellentétes előjelű valós pár vagy komplex konjugált pár), akkor a módszer általában nem konvergál egyetlen irányhoz, hanem oszcillál. A λ1=λ2\lambda_1=\lambda_2 többszörös esetben viszont az iteráció a sajátaltér egy vektorához konvergál.

A Rayleigh-hányados is λ1\lambda_1-hez tart. Ráadásul valós szimmetrikus mátrixnál, ha 𝐱k\mathbf{x}_k már közel van 𝐯1\mathbf{v}_1-hez, a hiba már nem az irány hibájával, hanem annak négyzetével arányos, tehát a Rayleigh-hányados jellemzően gyorsabban közelíti a sajátértéket. Ez abból következik, hogy az r(𝐱)=𝐱⊤𝐀𝐱𝐱⊤𝐱r(\mathbf{x})=\frac{\mathbf x^\top\mathbf A\mathbf x}{\mathbf x^\top\mathbf x} hányados gradiense szimmetrikus 𝐀\mathbf A esetén a 𝐯1\mathbf v_1 egységsajátvektornál nulla, ezért a Taylor-sorban a lineáris tag eltűnik: r(𝐯1+𝐞)=λ1+O(∥𝐞∥2)r(\mathbf v_1+\mathbf e)=\lambda_1+O(\|\mathbf e\|^2). A fenti táblázatban ennek megfelelően a Rayleigh-hiba lépésenként körülbelül 1/91/9-ére csökken, míg az irányhiba csak 1/31/3-ára, mert |λ2/λ1|2=1/9|\lambda_2/\lambda_1|^2=1/9.

16.3.5.1 Kitekintés: inverz iteráció, eltolás, QR-algoritmus

Inverz iteráció. Ha nem a domináns, hanem egy adott μ\mu értékhez közeli sajátértékhez tartozó sajátvektort keressük, a hatványiterációt a (𝐀−μ𝐈)−1(\mathbf A-\mu\mathbf I)^{-1} mátrixra alkalmazzuk; ezt nevezik inverz iterációnak (eltolásos inverz iteráció). A konvergenciát ilyenkor a |λi−μ||\lambda_i-\mu| értékek aránya szabályozza, ezért a μ\mu-höz legközelebbi sajátérték iránya válik dominánssá. A gyakorlatban minden lépésben egy 𝐀−μ𝐈\mathbf A-\mu\mathbf I együtthatós lineáris rendszert kell megoldani.

Eltolás és QR-algoritmus. A QR-algoritmus egyszerre közelíti az összes sajátértéket: ismételten kiszámítja az 𝐀k=𝐐k𝐑k\mathbf A_k=\mathbf Q_k\mathbf R_k QR-felbontást, majd az 𝐀k+1=𝐑k𝐐k\mathbf A_{k+1}=\mathbf R_k\mathbf Q_k szorzatot képezi. Mivel 𝐀k+1=𝐐k⊤𝐀k𝐐k\mathbf A_{k+1}=\mathbf Q_k^\top\mathbf A_k\mathbf Q_k, a mátrixok ortogonálisan hasonlók, sajátértékeik változatlanok. A gyakorlatban eltolással gyorsítják: a μk\mu_k eltolással a 𝐀k−μk𝐈=𝐐k𝐑k\mathbf A_k-\mu_k\mathbf I=\mathbf Q_k\mathbf R_k felbontást számítják, és 𝐀k+1=𝐑k𝐐k+μk𝐈\mathbf A_{k+1}=\mathbf R_k\mathbf Q_k+\mu_k\mathbf I; a +μk𝐈+\mu_k\mathbf I tagot azért kell visszaadni, mert 𝐐k⊤(𝐀k−μk𝐈)𝐐k=𝐑k𝐐k\mathbf Q_k^\top(\mathbf A_k-\mu_k\mathbf I)\mathbf Q_k=\mathbf R_k\mathbf Q_k, tehát 𝐀k+1=𝐐k⊤𝐀k𝐐k\mathbf A_{k+1}=\mathbf Q_k^\top\mathbf A_k\mathbf Q_k ilyenkor is teljesül.

A határérték alakja a számtesttől függ. Valós aritmetikában a sorozat felső kvázi-háromszög alakhoz, azaz valós Schur-alakhoz tart: a főátló alatt csak a nemvalós konjugált sajátértékpárokhoz tartozó 2×22\times2-es blokkok maradhatnak meg. Valós ortogonális hasonlósággal ugyanis a 90∘90^\circ-os síkbeli forgatás nem vihető valódi felső háromszög alakra, mert nincs valós sajátvektora (13.4. alfejezet, Forgatások és komplex sajátértékek röviden). Komplex aritmetikában a határérték felső háromszög, azaz komplex Schur-alak, amelynek főátlójában a sajátértékek állnak.

A NumPy két függvénye más-más úton jut el ide. A np.linalg.eig általános, nem feltétlenül szimmetrikus mátrixra a LAPACK _geev rutinjait használja: a mátrixot előbb Hessenberg-alakra hozza, majd eltolásos QR-iterációval állítja elő a Schur-alakot és a sajátértékeket. A np.linalg.eigh ezzel szemben valós szimmetrikus vagy komplex Hermite-mátrixra készült, és a LAPACK _syevd, illetve _heevd rutinjait hívja, amelyek divide-and-conquer (oszd meg és uralkodj) eljárással diagonalizálnak; ez nem az itt bemutatott egyszerű QR-iteráció. A részletes algoritmusok és konvergenciabizonyításaik túlmutatnak ezen a fejezeten; a 13.2. alfejezetben (Sajátértékek kiszámítása: a karakterisztikus egyenlet) említett QR-alapú iterációt ez a rövid áttekintés zárja le.

16.3.7 Számítógépes ellenőrzés NumPy-val

Az alábbi kód ugyanezt a példát futtatja:

import numpy as np

A = np.array([[2.0, 1.0],
              [1.0, 2.0]])
x = np.array([1.0, 0.0])

for k in range(1, 6):
    y = A @ x
    x = y / np.linalg.norm(y)
    r = x @ (A @ x)      # mert x normált, tehát x^T x = 1
    print(f"k={k}, x={np.round(x, 4)}, Rayleigh={r:.4f}")

Várt kimenet:

k=2, x=[0.7809 0.6247], Rayleigh=2.9756
k=3, x=[0.7328 0.6805], Rayleigh=2.9973
k=4, x=[0.7158 0.6983], Rayleigh=2.9997
k=5, x=[0.71   0.7042], Rayleigh=3.0000

Megállási szabály. A gyakorlatban nem elég néhány lépést futni: meg kell adni egy toleranciát és egy maximális iterációszámot. Az irány konvergenciáját előjelfüggetlenül kell mérni, mert negatív λ1\lambda_1 esetén 𝐱k\mathbf{x}_k és 𝐱k−1\mathbf{x}_{k-1} előjele ellentétes lehet: dk=min{∥𝐱k−𝐱k−1∥,∥𝐱k+𝐱k−1∥}. d_k=\min\{\|\mathbf{x}_k-\mathbf{x}_{k-1}\|,\ \|\mathbf{x}_k+\mathbf{x}_{k-1}\|\}. Ez azonban csak kiegészítő megállási jel: az irány megállhat úgy is, hogy a sajátvektor-egyenlet maradéka még nagy. Az elfogadást a sajátpár relatív maradéka igazolja: ρk=r(𝐱k),relk=∥𝐀𝐱k−ρk𝐱k∥(∥𝐀∥F+|ρk|)∥𝐱k∥. \rho_k=r(\mathbf{x}_k),\qquad \text{rel}_k=\frac{\|\mathbf{A}\mathbf{x}_k-\rho_k\mathbf{x}_k\|}{(\|\mathbf{A}\|_F+|\rho_k|)\,\|\mathbf{x}_k\|}. A nevező a mátrix és a sajátérték nagyságához viszonyít, ezért relk\text{rel}_k skálázásfüggetlen: ha 𝐀\mathbf{A}-t egy c≠0c\ne0 konstanssal szorozzuk, a relatív maradék – és vele a konvergált státusz és az elért iránypontosság – ugyanaz marad. Az abszolút és a relatív toleranciát külön kell megadni: az irányváltozásra egy abszolút atol, a relatív maradékra egy rtol küszöböt használunk. „Konvergált” státuszt csak akkor adunk, ha relk<rtol\text{rel}_k<\text{rtol}; ha dk<atold_k<\text{atol}, de a relatív maradék még nagy, az iteráció leáll, a státusz viszont „nem konvergált”. Ha a maximális lépésszámot eléri, a státusz szintén „nem konvergált”. A nevező a nullmátrixnál nulla lenne, ezért azt az esetet külön kezeljük. A függvény a bemeneteket is ellenőrizze: négyzetes, véges elemű mátrix, megfelelő alakú, véges és nemnulla kezdővektor, pozitív egész maxit, pozitív véges toleranciák; hibás bemenetre világos ValueError jöjjön, ne egy késleltetett NaN. A függvény adjon vissza konvergenciastátuszt is, ne csak a vektort. Ha ∥𝐀𝐱k−1∥=0\|\mathbf{A}\mathbf{x}_{k-1}\|=0, a normalizálás nem végezhető el; ilyenkor az algoritmus álljon le hibajelzéssel. Ez akkor fordulhat elő, ha 𝐀\mathbf{A} ranghiányos és a kezdővektor a nulltérben van, vagy ha 𝐀=𝟎\mathbf{A}=\mathbf{0}. Ha a kezdővektorban nincs domináns komponens, a módszer egy másik sajátpárhoz konvergál; a visszaadott státusz ilyenkor is „konvergált” lehet, ezért a dominanciát külön kell ellenőrizni (például több kezdővektorral vagy más becsléssel).

16.3.8 PageRank mint domináns sajátvektor egy kis gráfon

Egy Markov-mátrix elemei nemnegatívak, és a sorok összege 11. A puszta 𝐏⊤\mathbf{P}^\top iteráció azonban nem minden Markov-láncra konvergál: periodikus láncnál (például 𝐏=[0110]\mathbf{P}=\begin{bmatrix}0&1\\1&0\end{bmatrix}) a vektor váltakozik, reducibilis láncnál a stacionárius eloszlás nem feltétlenül egyértelmű (több zárt kommunikációs osztály esetén mindegyik hordoz magán stacionárius eloszlást, és ezek konvex kombinációi is azok; egyetlen zárt osztálynál viszont egyértelmű), a kimenő él nélküli (dangling) csúcsok pedig nulla sorösszeget adnak. A PageRank ezért a 𝐏\mathbf{P} dangling sorait előbb egyenletes eloszlással pótolja (ezzel azokat sor-sztochasztikussá teszi), majd a 𝐀=α𝐏⊤+(1−α)𝐯𝟏⊤ \mathbf{A}=\alpha\mathbf{P}^\top+(1-\alpha)\mathbf{v}\mathbf{1}^\top teleportációs mátrixot használja, ahol 𝟏=(1,…,1)⊤\mathbf{1}=(1,\dots,1)^\top, 0<α<10<\alpha<1 és 𝐯>0\mathbf{v}>0 pozitív preferenciavektor, ∑ivi=1\sum_i v_i=1. Ekkor 𝐀\mathbf{A} oszlopai nemnegatívak, összegük 11, és α<1\alpha<1 miatt pozitív; a domináns sajátérték 11 egyszeres, ezért a hatványiteráció az 𝐱=𝐀𝐱\mathbf{x}=\mathbf{A}\mathbf{x} stacionárius eloszláshoz konvergál.

A következő mini példa egy erősen összefüggő, periodicitásmentes láncot mutat, ahol a teleportáció nélkül is konvergál; ez csak a stacionárius eloszlás kiszámítását szemlélteti, nem a teljes PageRank-algoritmust. A miniweb a weblapok közötti véletlen bolyongás leegyszerűsített modellje. Képzeljünk el egy miniwebet két lappal. Az 1. oldalról 0,40{,}4 valószínűséggel maradunk ott, és 0,60{,}6-tal lépünk a 2. oldalra; a 2. oldalról 0,70{,}7 valószínűséggel lépünk az 1. oldalra, és 0,30{,}3-mal maradunk a 2. oldalon. Az átmenetmátrix elemei nemnegatívak, a sorok összege 11: 𝐏=[0,40,60,70,3]. \mathbf{P}=\begin{bmatrix} 0{,}4 & 0{,}6\\ 0{,}7 & 0{,}3 \end{bmatrix}. A keresett 𝐱\mathbf{x} stacionárius eloszlás az a vektor, amelyre 𝐱=𝐏⊤𝐱\mathbf{x}=\mathbf{P}^\top \mathbf{x}. Ezért az 𝐀=𝐏⊤=[0,40,70,60,3] \mathbf{A}=\mathbf{P}^\top=\begin{bmatrix} 0{,}4 & 0{,}7\\ 0{,}6 & 0{,}3 \end{bmatrix} mátrix domináns sajátvektorát keressük. Az 𝐀\mathbf{A} sajátértékei 11 és −0,3-0{,}3, tehát a domináns sajátérték λ1=1\lambda_1=1, a konvergenciasebesség |λ2/λ1|=0,3|\lambda_2/\lambda_1|=0{,}3.

Induljunk az 𝐱0=(1,0)\mathbf{x}_0=(1,0) vektorból, és végezzünk el néhány hatványiterációs lépést (négy tizedesre kerekítve). Normálásra itt nincs szükség: mivel 𝐀=𝐏⊤\mathbf{A}=\mathbf{P}^\top oszlopösszegei 11-ek, a komponensek összege minden lépésben 11 marad, tehát 𝐱k\mathbf{x}_k végig valószínűségeloszlás.

Miért kell a teleportáció? A 𝐏=[0110]\mathbf{P}=\begin{bmatrix}0&1\\1&0\end{bmatrix} mátrixnál 𝐀0=𝐏⊤\mathbf{A}_0=\mathbf{P}^\top sajátértékei 11 és −1-1, ezért |λ1|=|λ2||\lambda_1|=|\lambda_2|, és az 𝐱0=(1,0)\mathbf{x}_0=(1,0) vektorból indított iteráció 𝐱1=(0,1)\mathbf{x}_1=(0,1), 𝐱2=(1,0)\mathbf{x}_2=(1,0), …\dots módon váltakozik, nem konvergál. Az α=0,8\alpha=0{,}8, 𝐯=(0,5;0,5)\mathbf{v}=(0{,}5; 0{,}5) választással 𝐀=0,8𝐏⊤+0,2𝐯𝟏⊤=[0,10,90,90,1], \mathbf{A}=0{,}8\mathbf{P}^\top+0{,}2\mathbf{v}\mathbf{1}^\top =\begin{bmatrix}0{,}1&0{,}9\\0{,}9&0{,}1\end{bmatrix}, és 𝐱1=(0,1;0,9)\mathbf{x}_1=(0{,}1; 0{,}9), 𝐱2=(0,82;0,18)\mathbf{x}_2=(0{,}82; 0{,}18), majd az iteráció a (0,5;0,5)(0{,}5; 0{,}5) határértékhez tart. Az 𝐀\mathbf{A} sajátértékei 11 és −0,8-0{,}8, tehát |λ2|=0,8=α|\lambda_2|=0{,}8=\alpha: a (0,5;0,5)(0{,}5; 0{,}5)-től vett eltérés minden lépésben a −0,8-0{,}8-szorosára vált (0,40{,}4, 0,320{,}32, 0,2560{,}256, 0,20480{,}2048, …\dots), ezért a konvergencia lassú és előjelváltó. A PageRank konvergenciasebességét általában is a |λ2|≤α|\lambda_2|\le\alpha korlát szabályozza, ezért a kisebb α\alpha gyorsabb konvergenciát ad. A teleportáció tehát nem díszítés: biztosítja az egyértelmű domináns sajátvektort és a konvergenciát. A gyakorlatban a dangling csúcsok sorát előbb egyenletes eloszlással kell helyettesíteni, különben 𝐏\mathbf{P} nem lesz sor-sztochasztikus.

16.3.9 Kapcsolat a gépi tanulással

A spektrálnorma-normalizálás alapötletét a Mátrixnormák, spektrálnorma és kondíciószám alfejezetben már megismertük; itt azt nézzük meg, hogyan becsülhető a legnagyobb szinguláris érték, σmax(𝐖)=λmax(𝐖⊤𝐖)\sigma_{\max}(\mathbf{W})=\sqrt{\lambda_{\max}(\mathbf{W}^\top \mathbf{W})} hatványiterációval. Generatív ellenséges hálókban (GAN-okban) a spectral norm normalization néven ismert eljárás a diszkriminátor rétegeinek súlymátrixát osztja le a becsült σmax\sigma_{\max}-szal. Miyato és szerzőtársai 2018-as ICLR-cikke szerint a gyakorlatban elég néhány hatványiterációs lépés a becslésére, mert a súlyok lassan változnak. Ez azonban közelítő spektrális normalizálás, nem szigorú Lipschitz-garancia: a véges iteráció alulbecsülheti a valódi σmax\sigma_{\max}-ot, és ilyenkor a normalizált mátrix valódi spektrálnormája 11-nél nagyobb lehet. Szigorú korláthoz megbízható felső becslés vagy a normalizált mátrix külön normavizsgálata kell. A teljes hálózat Lipschitz-konstansa ráadásul a többi réteg és az aktivációk hatását is tartalmazza, nem csak ezt az egy réteget.

Legyen 𝐖∈ℝdki×dbe\mathbf{W}\in\mathbb{R}^{d_{\text{ki}}\times d_{\text{be}}}. A becsléshez egy véletlen 𝐮∈ℝdbe\mathbf{u}\in\mathbb{R}^{d_{\text{be}}} vektort futtatunk:

import numpy as np

rng = np.random.default_rng(0)
d_ki, d_be = 4, 3                  # kis játékméret
W = rng.standard_normal((d_ki, d_be))

def spectral_norm_becsles(W, u, steps=5):
    W = np.asarray(W, dtype=float)
    u = np.asarray(u, dtype=float)
    if W.ndim != 2:
        raise ValueError("a W legyen kétdimenziós mátrix")
    if W.size == 0:
        raise ValueError("a W ne legyen üres mátrix")
    if not np.all(np.isfinite(W)):
        raise ValueError("a W elemei legyenek végesek")
    if not isinstance(steps, (int, np.integer)) or isinstance(steps, bool) or steps <= 0:
        raise ValueError("a steps legyen pozitív egész")
    if u.ndim == 2:
        if u.shape[1] != 1:
            raise ValueError("az u alakja (d_be,) vagy (d_be,1) legyen")
    elif u.ndim != 1:
        raise ValueError("az u alakja (d_be,) vagy (d_be,1) legyen")
    if u.shape[0] != W.shape[1]:
        raise ValueError("az u hossza a W oszlopszáma legyen")
    if not np.all(np.isfinite(u)):
        raise ValueError("az u elemei legyenek végesek")
    if np.linalg.norm(u) == 0.0:
        raise ValueError("az u ne legyen nulla vektor")
    u = u / np.linalg.norm(u)
    for _ in range(steps):      # a gyakorlatban gyakran 1–5 lépés
        v = W @ u
        nv = np.linalg.norm(v)
        if nv == 0.0:
            raise ValueError(
                "a W @ u szorzat nulla; a hatványiteráció nem folytatható")
        v = v / nv
        u = W.T @ v
        nu = np.linalg.norm(u)
        if nu == 0.0:
            raise ValueError(
                "a W.T @ v szorzat nulla; a hatványiteráció nem folytatható")
        u = u / nu
    sigma = np.linalg.norm(W @ u)
    if sigma == 0.0:
        raise ValueError(
            "a becsült sigma_max nulla; a mátrix vagy a kezdővektor alkalmatlan")
    return sigma, u

u = rng.standard_normal((d_be, 1))
sigma, u = spectral_norm_becsles(W, u)
W_sn = W / sigma
print("becsült sigma_max:", np.round(sigma, 4))
print("pontos sigma_max: ", np.round(np.linalg.norm(W, 2), 4))
print("W_sn spektrálnormája:", np.round(np.linalg.norm(W_sn, 2), 4))

# Nulla és ranghiányos esetek: hibajelzés, nem NaN
for nev, M, kezdo in [
    ("nulla mátrix", np.zeros((2, 3)), np.ones((3, 1))),
    ("ranghiányos, rossz kezdővektor",
     np.diag([1.0, 0.0]), np.array([[0.0], [1.0]])),
]:
    try:
        spectral_norm_becsles(M, kezdo)
    except ValueError as e:
        print(nev + ":", e)

# Hibás bemenetek: dokumentált ValueError, nem NaN
for nev, hivas in [
    ("nulla kezdővektor", lambda: spectral_norm_becsles(W, np.zeros(d_be))),
    ("rossz alakú kezdővektor", lambda: spectral_norm_becsles(W, np.ones((3, 2)))),
    ("NaN a mátrixban", lambda: spectral_norm_becsles(np.array([[np.nan]]), np.ones(1))),
    ("steps=0", lambda: spectral_norm_becsles(W, np.ones((d_be, 1)), steps=0)),
]:
    try:
        hivas()
    except ValueError as e:
        print(nev + ":", e)

# Nem optimális kezdés: a becslés alulbecsülhet
W_d = np.diag([2.0, 1.0])
u_d = np.array([[0.0], [1.0]])      # a kisebb sajátérték iránya
sigma_d, _ = spectral_norm_becsles(W_d, u_d)
W_d_sn = W_d / sigma_d
print("diag(2,1) becsült sigma:", sigma_d)
print("diag(2,1) valódi sigma a normált mátrixban:",
      np.linalg.norm(W_d_sn, 2))

Itt a mátrixunk nem 𝐖⊤𝐖\mathbf{W}^\top\mathbf{W}, hanem a két lépésben alkalmazott 𝐖\mathbf{W} és 𝐖⊤\mathbf{W}^\top, ami elkerüli a nagy 𝐖⊤𝐖\mathbf{W}^\top\mathbf{W} mátrix képzését. Az 𝐮\mathbf{u} vektor a 𝐖⊤𝐖\mathbf{W}^\top\mathbf{W} domináns sajátvektorához, σmax\sigma_{\max} pedig a spektrálnormához konvergál. Az 𝐖sn=𝐖/σmax\mathbf{W}_{\text{sn}}=\mathbf{W}/\sigma_{\max} becsült normával osztott súlymátrix a gyakorlatban csökkenti a réteg nyújtását, de a becslés véges iterációból származik, ezért nem ad szigorú Lipschitz-garanciát. A diag(2,1)\operatorname{diag}(2,1) példa ezt mutatja: a kisebb sajátérték irányából indított iteráció σmax\sigma_{\max}-ra 11-et becsül, a normált mátrix valódi legnagyobb szinguláris értéke viszont 22, tehát a réteg a „normalizálás” után is kétszeres nyújtást végezhet. Szigorú korlát csak megbízható felső becsléssel vagy a normalizált mátrix külön normavizsgálatával érhető el. A nulla szorzatot a kód explicit ValueError-ral jelzi, mert a 0/00/0 osztás NaN-t adna; ez akkor fordulhat elő, ha 𝐖=𝟎\mathbf{W}=\mathbf{0}, vagy ha egy ranghiányos 𝐖\mathbf{W}-nél a kezdővektor a nulltérbe esik. Ilyenkor a hatványiterációt új kezdővektorral kell indítani, vagy a nullmátrixra külön nullát kell visszaadni. A függvény a bemeneteket is ellenőrzi: nem megfelelő alakú vagy nem véges elemű mátrix, rossz alakú, nem véges vagy nulla kezdővektor, illetve nem pozitív egész steps esetén a számolás megkezdése előtt ValueError-t ad.

16.3.10 Tipikus hibák és félreértések

  1. Normálás kihagyása. Az 𝐀k𝐱0\mathbf{A}^k\mathbf{x}_0 vektor hossza |λ1|k|\lambda_1|^k-nal exponenciálisan nő, így lebegőpontos túlcsordulás vagy nullához tartás léphet fel. Minden lépésben normálni kell.

  2. A konvergencia feltételének elfelejtése. Ha |λ1|=|λ2||\lambda_1|=|\lambda_2|, de λ1≠λ2\lambda_1\ne\lambda_2 (például komplex konjugált pár vagy ellentétes előjelű valós pár), az irány oszcillálhat, és a módszer nem ad egyetlen domináns sajátvektort. A λ1=λ2\lambda_1=\lambda_2 többszörös eset kivétel: ilyenkor az iteráció konvergál, csak a sajátaltéren belül nem egyértelmű, melyik irányhoz.

  3. Rossz kezdővektor. Ha a kezdővektor sajátbázisbeli kifejtésében c1=0c_1=0, akkor elvileg a második legnagyobb sajátértékhez tartozó irányhoz konvergál. Ez nem azonos azzal, hogy 𝐱0\mathbf{x}_0 euklideszi értelemben merőleges a domináns jobb sajátvektorra: nem szimmetrikus 𝐀\mathbf{A} esetén a c1=0c_1=0 feltétel a bal sajátvektorral való merőlegességet jelenti, azaz 𝐰1⊤𝐱0=0\mathbf{w}_1^\top\mathbf{x}_0=0. Szimmetrikus 𝐀\mathbf{A} esetén a bal és a jobb sajátvektor megegyezik, ezért ott a szokásos euklideszi merőlegesség valóban c1=0c_1=0-t ad. A numerikus kerekítési hibák miatt c1c_1 rendszerint megjelenik, de a gyakorlatban jobb véletlen kezdővektort választani.

  4. A Rayleigh-hányados nevezőjének elhagyása. Csak normált vektornál igaz, hogy r(𝐱)=𝐱⊤𝐀𝐱r(\mathbf{x})=\mathbf{x}^\top\mathbf{A}\mathbf{x}. Általános esetben a (𝐱⊤𝐀𝐱)/(𝐱⊤𝐱)(\mathbf{x}^\top\mathbf{A}\mathbf{x})/(\mathbf{x}^\top\mathbf{x}) hányadost kell használni.

16.3.12 Megoldások

(a) A karakterisztikus egyenlet n×nn\times n-es mátrixra egy nn-edfokú polinom gyökeinek keresését igényli, ami nn nagy értékére drága és numerikusan érzékeny. A hatványiteráció csak mátrix–vektor szorzást használ, így hatalmas ritka mátrixokra is hatékony. A |λ2/λ1||\lambda_2/\lambda_1| hányados add meg, hogy az irányhiba aszimptotikusan hányszorosára csökken egy lépés alatt.

(b) Az 𝐀\mathbf{A} sajátértékei 44 és 22, domináns sajátvektora (1,1)/2(1,1)/\sqrt{2}, a konvergenciasebesség 2/4=0,52/4=0{,}5. Első lépés: 𝐲1=𝐀𝐱0=(3,1),∥𝐲1∥=10≈3,1623,𝐱1≈(0,9487;0,3162). \mathbf{y}_1=\mathbf{A}\mathbf{x}_0=(3,1),\quad \|\mathbf{y}_1\|=\sqrt{10}\approx 3{,}1623,\quad \mathbf{x}_1\approx(0{,}9487;\; 0{,}3162). import numpy as np

def power_iteration(A, maxit=1000, rtol=1e-8, atol=1e-8, x0=None):
    A = np.asarray(A, dtype=float)
    if A.ndim != 2 or A.shape[0] != A.shape[1]:
        raise ValueError("az A legyen négyzetes mátrix")
    if A.size == 0:
        raise ValueError("az A ne legyen üres mátrix")
    if not np.all(np.isfinite(A)):
        raise ValueError("az A elemei legyenek végesek")
    if not isinstance(maxit, (int, np.integer)) or isinstance(maxit, bool) or maxit <= 0:
        raise ValueError("a maxit legyen pozitív egész")
    if not np.isfinite(rtol) or rtol <= 0:
        raise ValueError("az rtol legyen pozitív véges szám")
    if not np.isfinite(atol) or atol <= 0:
        raise ValueError("az atol legyen pozitív véges szám")
    rng = np.random.default_rng(0)
    if x0 is None:
        x = rng.standard_normal(A.shape[0])
    else:
        x = np.asarray(x0, dtype=float)
        if x.ndim == 2 and x.shape[1] == 1:
            x = x.ravel()
        if x.ndim != 1 or x.shape[0] != A.shape[0]:
            raise ValueError("az x0 alakja (n,) vagy (n,1) legyen")
        if not np.all(np.isfinite(x)):
            raise ValueError("az x0 elemei legyenek végesek")
        if np.linalg.norm(x) == 0.0:
            raise ValueError("az x0 ne legyen nulla vektor")
    x = x / np.linalg.norm(x)
    norm_A = np.linalg.norm(A, "fro")
    status = "nem konvergalt"
    abs_maradek = rel_maradek = np.inf
    for k in range(1, maxit + 1):
        y = A @ x
        ny = np.linalg.norm(y)
        if ny == 0.0:
            return np.nan, x, "Ax=0, nincs domináns irány", k, np.inf, np.inf
        x_new = y / ny
        # negatív domináns sajátértéknél x előjele lépésenként váltakozik
        valtozas = min(np.linalg.norm(x_new - x), np.linalg.norm(x_new + x))
        x = x_new
        rayleigh = x @ A @ x
        abs_maradek = np.linalg.norm(A @ x - rayleigh * x)
        rel_maradek = abs_maradek / ((norm_A + abs(rayleigh)) * np.linalg.norm(x))
        if rel_maradek < rtol:
            status = "konvergalt"
            break
        if valtozas < atol:   # kiegészítő jel: az irány megállt
            status = "nem konvergalt (az irány megállt, de a relatív maradék nagy)"
            break
    rayleigh = x @ A @ x
    return rayleigh, x, status, k, abs_maradek, rel_maradek

B = np.random.default_rng(0).standard_normal((5, 5))
A = B + B.T

lam_dom = w[np.argmax(np.abs(w))]    # legnagyobb abszolút értékű sajátérték
